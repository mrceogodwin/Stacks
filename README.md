# Stacks.ng

Production showroom and generation engine for [stacks.ng](https://stacks.ng).

Public site is light by default: apps I built, 500+ free tools, a Premium Tools lane, and an explainer film. No Studio, no admin, no secrets on the public film.

- **500+ tools** — each tool has its own fields. Run, regenerate, copy, share, save, and download as DOC / PDF / TXT / HTML / PNG / MP4 / WAV depending on kind.
- **Premium Tools** — Stacks Engine, Music Generator, Effects & Sound, Cinematic Video, Image Studio Pro. Register at `/account`, pay in crypto, submit the amount. The owner approves. Wallet shows generations left.
- **Engine** — up to 100 live API keys, rotated automatically when a key is spent. Music and sound render as original WAV without an LLM key.
- **Owner console** — hidden. First signed-in owner on the private command path locks it.

Built as a TanStack Start app. Point stacks.ng at the production URL after publish.
